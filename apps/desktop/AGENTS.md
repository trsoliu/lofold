# LoFold 界面约束

## 列表拖动排序

桌面侧栏的邮箱账号以及同类可排序的同级列表项，直接按住整行拖动。界面不额外放置可见拖动手柄，也不为手柄预留空间。

单击继续执行行原有动作。越过拖动阈值后才进入排序，拖动结束或取消都不得再触发单击。拖动时标出当前落点，只在有效落点释放时保存顺序。同一项内的子项随父项整体移动，子项原有操作和选中状态继续保留。

保留键盘排序方式。验收覆盖单击、短距离移动、拖动释放、取消、键盘排序及重启后恢复。

## 紧凑列表排版

附件、账号、草稿、会话和其他单行列表采用可收缩的文本区域。标题和摘要分别以单行省略，保留完整文本及悬停提示。操作组和时间保留所需宽度。验收使用长文件名、长邮箱地址及长标题，检查窄窗和宽窗中的按钮对齐、键盘操作及横向溢出。

## 读信排版

修改 HTML 邮件渲染时，短表头和状态保留完整单词。正文、代码和超长链接应随栏宽换行，代码原有缩进和换行继续保留。过宽表格在自身区域滚动。保留符合安全范围的列宽、合并关系、图片比例、历史顺序和长图正文。

改动共用渲染规则后，至少复验合成邮件中的窄列、嵌套旧式表、长链接、代码、固定宽度图文和多轮引用。覆盖宽窗、窄窗、浅色、暗色与长图。新增或删除自定义渲染规则时同步更新这些场景，避免通过压小字号、裁掉文字或为单个发件方写特例来通过验收。
