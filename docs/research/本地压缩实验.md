# 本地邮件与附件的无损压缩实验

2026-11-20 · macOS arm64 · 全部样本由脚本生成。原始 EML、附件和索引记录中的文件名都没有取自用户邮箱。测试在本机内存及临时目录运行。[样本生成与校验脚本](../../scripts/research/本地压缩对照.py)

在这批样本中，带 JPEG 附件的完整邮件从 231,888 字节缩到 174,816 字节，两个临时文件所占的磁盘块相差 56 KiB。把同一张 JPEG 单独保存时，直接保留原始文件。短中文邮件在压缩后只剩 550 字节，但原件与压缩件各自都占一个 4 KiB 块。能向用户展示多少实际磁盘收益，取决于对象大小、文件系统及最终存储格式。

## 测量方式

- **整件对照。** 对每份原始字节分别执行 Zstandard 1、3、6 级压缩（单线程，带帧校验），再执行 zlib 6 级的 DEFLATE（含 zlib 封装）。每次都从压缩结果解压，逐字节比较，并核对 SHA-256。
- **分块策略。** 以 256 KiB 切块。少于 1 KiB 的块直接保存；独立 JPEG、ZIP 按文件签名旁路。其余块试用 Zstandard 3，只有节省至少 `max(64 字节, ceil(原块字节数 × 1%))` 时才采用。PDF 容器和原始 EML 都参与试压，MIME 中的 base64 和换行保持原样。最终把每块还原并拼回原件，重复同样的相等性检查。
- **指标。** 载荷字节数含压缩帧；原样块按自身字节数计。节省率为 `(原始字节数 − 所选载荷字节数) / 原始字节数`。另在相同临时目录分别落盘两个文件，写入后调用 `fsync`，读取 `st_blocks × 512` 记录本机文件系统报告的已分配字节。分块载荷连续写入一个文件。

24 条行程和 16,000 条 CSV 明细由有规律的模板生成，重复度高。PDF、独立 JPEG 及邮件附件里的图片是同一份合成字节，脚本从 EML 解码附件后也核对了它与独立 JPEG 相等。八类样本回答不同问题，不能把这些文件简单相加当作一个用户邮箱的构成。对于这份 CSV，Zstandard 1 产生的整件载荷最小；预设级别的编号不能代替在目标设备上比较耗时与空间。

## 正确性与范围

8 个样本各验证 3 个 Zstandard 级别、1 个 zlib 级别和分块策略，共 **40 次原字节与 SHA-256 对照**，均通过。另有一个 512 KiB 加 512 B 的混合对象，依次含可压的固定字节、高熵段及短尾块。实际选择依次为压缩、原样、原样，串联解码还原成功。独立的格式复核中，两份 PDF 通过 `pdfinfo` 识别为单页，JPEG 经 `djpeg` 解码为 640 × 480，ZIP 解包后的合成成员为 98,304 字节。

以上磁盘列只包含两个普通载荷文件。对象头、块表、加密标签、SQLite/FTS、WAL、临时预览、备份、快照和缓存均不在本次空间口径内。当前数据也未测四端空间、耗电、峰值内存或实时吞吐。用于产品优势说明前，应在同一批脱机合成邮箱、相同缓存范围与同一加密格式下，分别测压缩开关两种状态的完整档案占用、首次同步耗时、定位后读信和附件导出的时延。

## 复跑

环境为 Python 3.11.2、Zstandard CLI 1.5.7、libjpeg-turbo `cjpeg` 3.2.0、zlib 1.2.12。脚本没有 Python 第三方包依赖；运行时需在 PATH 上找到 `zstd` 与 `cjpeg`。新版本编码器或不同文件系统的载荷大小、分配块数可能变化，脚本会同时输出工具版本和每个原件的 SHA-256。示例中 JPEG 像素来自确定性纹理，ZIP 成员由固定种子的 SHAKE-256 产生。测试创建的载荷临时文件在测完后自动清理。

```sh
python3 -B scripts/research/本地压缩对照.py
```


## 独立 Rust 组件复验

[mail-blob-codec 源码](../../packages/mail-blob-codec/src/lib.rs) 提供单块写入与有界读取。原样和 Zstandard 共用 12 B 的版本化记录头。组件使用 3 级，依赖锁定为 zstd 0.13.5／libzstd 1.5.7。上表使用命令行帧，未计 Rust 记录头或加密标签；不同写入器的帧选项也可影响字节数。组件在本机 macOS 构建，8 个回归用例覆盖原样与压缩、选取阈值、固定参考帧、长度限制及损坏记录。另将上述 8 种合成文件按最多 256 KiB 切块，经库的公开接口逐块编码和解码后与原文件比较，8 种均逐字节一致。存储层负责块的认证、顺序、整件哈希与原子提交，待底座接入后验证。

在项目根目录复跑组件回归测试。已有锁定依赖缓存时可增加 `--offline`。

```sh
cargo test --locked --manifest-path packages/mail-blob-codec/Cargo.toml
```
