# 本机 AI

LoFold 连接同一台 Mac 上的 Ollama。已安装的 GGUF 对话模型会出现在模型列表中。模型由用户管理，LoFold 可以随邮件收发一起工作，也可以断网处理已经缓存的正文。

## 启用

启动 Ollama 并关闭云功能。可以设置 Ollama 的 `disable_ollama_cloud`，也可以在终端用以下命令启动已经安装的 Ollama。已有服务器运行时，修改配置后重启该服务。[Ollama 本地模式说明](https://docs.ollama.com/faq#how-do-i-disable-ollamas-cloud-features)

```sh
OLLAMA_HOST=127.0.0.1:11434 OLLAMA_NO_CLOUD=1 ollama serve
```

如果机器没有模型，可以自行安装适合本机内存的 GGUF 对话模型。例如在另一终端执行 `ollama pull qwen2.5:3b`。下载模型需要联网。安装后在 LoFold 内刷新列表。

## 使用

| 入口 | 操作 |
| --- | --- |
| 侧栏「AI 查信」 | 选定邮箱或整个本机归档，输入自然语言问题。点击参考原信可阅读邮件，返回时保留问题和结果。 |
| 邮件操作栏「本机 AI」 | 对当前邮件生成摘要、翻译为中英日韩文或按指令拟回复。确认后用拟稿创建回复草稿。 |
| 写信窗口「AI 拟稿」 | 描述写信要求，预览生成正文，再选择插入当前草稿。 |

问答先提取关键词，再从本机索引检索候选，将最多五封的文本片段交给同一个模型。无命中时明确显示搜索范围没有匹配邮件。单封处理最多读取正文前 7,000 个字符，长文翻译分段；截断或达到模型输出上限时会在界面提示。结果是供核对的文本，发送仍须在写信窗口确认。

## 验证

用合成邮件运行真实模型联测。默认模型为 `qwen2.5:3b`，也可设置 `LOFOLD_AI_TEST_MODEL` 选择已经安装的本机模型。常规 CI 使用确定性回归用例。

```sh
cargo test --locked -p lofold-client real_local_model_reads_synthetic_mail_and_writes_text_results -- --ignored
```
