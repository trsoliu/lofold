# 大模型配置与邮件 AI

在「设置 → 大模型」选择模型服务。查信、摘要、翻译、拟回复和写信拟稿共用当前选择。

## 选择接口协议

在「设置 → 大模型」选用服务提供的协议。**基础地址**填到版本或网关前缀为止，LoFold 会追加相应的接口路径。模型 ID 可以按服务商提供的名称直接填写，也可以读取模型列表后选择。保存后，查信、读信和写信共用这份配置。

| 协议 | 基础地址示例 | LoFold 使用的生成接口 |
| --- | --- | --- |
| OpenAI Chat Completions | `https://api.openai.com/v1`，也可填写自建服务的地址 | [`/chat/completions`](https://platform.openai.com/docs/api-reference/chat/create) |
| OpenAI Responses | `https://api.openai.com/v1` | [`/responses`](https://platform.openai.com/docs/api-reference/responses/create) |
| Anthropic Messages | `https://api.anthropic.com/v1` | [`/messages`](https://platform.claude.com/docs/en/api/messages/create) |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta` | [`/models/{模型 ID}:generateContent`](https://ai.google.dev/api/generate-content) |
| Ollama | 默认 `http://127.0.0.1:11434`，端口可改 | `/api/chat` |

服务要求鉴权时填写该协议的 API Key。LoFold 按协议和完整基础地址在系统凭据存储中分别保存密钥。即使 Chat Completions 和 Responses 使用同一个网站，也要分别配置。升级前的 OpenAI 兼容设置沿用 Chat Completions，已有的 Ollama 端口及模型也可继续使用。

远程服务使用 HTTPS。执行邮件 AI 操作时，界面显示本次目的地、用途和将提供的内容，确认后才发送。远程查信分两步确认。第一次只发送问题以提取关键词。LoFold 在本机检索并列出最多五封命中邮件的具体标题和摘录，再次确认后，服务才收到这些摘录以生成答案。拟稿可能包含原信、已有草稿及本次选择的写作资料。本机回环服务也支持 HTTP；其是否继续转发请求取决于该服务的配置。

## 本机 Ollama

启动 Ollama 并关闭云功能。可以设置 Ollama 的 `disable_ollama_cloud`，也可以在终端用以下命令启动已经安装的 Ollama。已有服务器运行时，修改配置后重启该服务。[Ollama 本地模式说明](https://docs.ollama.com/faq#how-do-i-disable-ollamas-cloud-features)

```sh
OLLAMA_HOST=127.0.0.1:11434 OLLAMA_NO_CLOUD=1 ollama serve
```

如果机器没有模型，可以自行安装适合本机内存的 GGUF 对话模型。例如在另一终端执行 `ollama pull qwen2.5:3b`。下载模型需要联网。安装后打开 LoFold 的「设置 → 大模型」的 Ollama 选项，点击「刷新模型」并选择模型。查信、读信和写信共用此选择。

若 Ollama 监听其他本机端口，在同一设置页的「Ollama 端口」中填写服务实际端口并点击「应用本机端口」。LoFold 会记住选择，只连接 `127.0.0.1`。使用非默认端口时，服务还须能通过 `/api/status` 确认云功能已关闭。

## 使用

| 入口 | 操作 |
| --- | --- |
| 侧栏「AI 查信」 | 选定邮箱或整个本机归档，输入自然语言问题。点击参考原信可阅读邮件，返回时保留问题和结果。 |
| 邮件操作栏「邮件 AI」 | 对当前邮件生成摘要、翻译为中英日韩文或按指令拟回复。确认后用拟稿创建回复草稿。 |
| 写信窗口「AI 拟稿」 | 空白正文可按要求拟稿，已有正文可续写或润色。预览后插入或替换，刚替换的正文可在写信窗口撤销。 |

问答先提取关键词，再从本机索引检索候选，将最多五封的文本片段交给同一个模型。无命中时明确显示搜索范围没有匹配邮件。单封处理最多读取正文前 7,000 个字符，长文翻译分段；截断或达到模型输出上限时会在界面提示。结果是供核对的文本，发送仍须在写信窗口确认。

## 写作资料与记忆

在「设置 → 写信」选择资料所属邮箱，填写姓名或称呼、写信身份、常用语气、偏好篇幅和签名。每个发件邮箱有自己的资料，未选择发件邮箱的草稿使用单独的一份。资料保存在本机加密归档中。移除某个邮箱会同时清除其写作资料。

写邮件时，选中正文中的一句话，打开工具栏的书本图标「写作记忆」即可保存。每份资料可存 24 条，每条最多 300 字。只有一位明确的收件人时，保存范围默认选中该地址，也可以改为这个发件身份通用。多人邮件、带抄送或密送的邮件仅显示通用表述。表述可插在光标处，选择了文字时会替换选区；签名通过「插入签名」追加到文末。这些操作均可离线使用。通过面板里的「编辑写作资料」可直接修改、删除已记住的内容。

使用 AI 拟稿时，展开「查看资料」可核对称呼、身份、语气和篇幅，选择本次要参考的表述（最多四条）。关闭「使用本次写作资料」可只按本次要求生成。续写参考主题及正文末尾最多 1,400 字。整篇润色支持 2,000 字以内的正文，结果由用户预览后替换。生成后修改收件人、发件人、正文或写信要求，需重新生成。阅读原信时的「拟回复」只使用发件账号已明确的资料，此时地址专属表述留到打开回复草稿后选用。查信、摘要和翻译沿用各自的邮件输入。

## 验证

在回环服务上使用合成邮件复验协议。设置 `LOFOLD_AI_TEST_BASE_URL` 和 `LOFOLD_AI_TEST_MODEL`，并通过 `LOFOLD_AI_TEST_PROTOCOL` 选择 `chat_completions`、`responses`、`anthropic` 或 `gemini`。

```sh
cargo test --locked -p lofold-client real_compatible_model_reads_synthetic_mail_and_writes_text_results -- --ignored
```

Ollama 联测的默认模型为 `qwen2.5:3b`，可设置 `LOFOLD_AI_TEST_MODEL` 选择已经安装的本机模型，并用 `LOFOLD_AI_TEST_PORT` 指定服务端口。常规 CI 使用确定性回归用例。

```sh
cargo test --locked -p lofold-client real_local_model_reads_synthetic_mail_and_writes_text_results -- --ignored
cargo test --locked -p lofold-client real_local_model_polishes_with_an_explicitly_selected_phrase -- --ignored
```
