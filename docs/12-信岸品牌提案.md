# 信岸 · 首轮品牌记录

当前选款采用[三套英文品牌与四套界面主题](13-英文品牌与界面主题选款.md)。

**产品候选名**　信岸。面向应用商店的描述名可以用「信岸邮箱」，界面短名用「信岸」。

**Slogan**　多邮箱一处收，离线也能读。

![信岸标志、名称和 slogan](../output/brand/信岸-品牌预览.png)

「信」指邮件，「岸」表达收件后有一个固定去处。两层信件对应多邮箱汇入同一个工作区。墨绿底承接现有侧栏，纸白主信封负责小尺寸识别，浅绿信纸提供层次。

- 欢迎页使用完整组合，侧栏与审阅栏使用图标和短名，手机抽屉使用同一个图标。
- 浏览器标签页使用同一个图标。16、24、32 px 缩放示例见预览图，后续安装图标可以从矢量源稿导出。
- 「离线也能读」覆盖已同步到本机或已导入的邮件。按需下载的附件在缓存后可离线打开。
