# ADR 0001 工作区布局

2026-11-23 · 已采用

桌面端、原型和 Rust 模块原先分别保存在 `apps/client`、`prototype` 与 `crates`。桌面依赖原型目录才能取得主题和 Logo。迁移后，运行入口放在 `apps/`，可复用库放在 `packages/`，两个应用通过同一品牌包获得主题和标志。

pnpm 管理 JavaScript 依赖，Turborepo 调度前端任务。Cargo 管理 Rust 依赖和原生测试，Tauri 负责 macOS 安装包。两套工具链可以独立构建和缓存，顶层验收需执行两套检查。离线原型保留相对路径，Pages 仍从 `docs/` 直接部署。

应用标识和数据格式沿用现有契约。需要回滚时可反向提交路径和清单变更，继续读原有归档。新路径及依赖方向详见 [代码地图](../../CODEMAP.md)。
