# 本地邮箱交互原型

进入[原型审阅](../prototype/review.html)，点击「流程目录」即可切换日常操作和异常状态。首轮高保真可直接体验[多邮箱收件与回复](../prototype/review.html#live/hi-fi)。画板、两端布局、组件状态及验收路径见[原型定稿与高保真交接](11-原型定稿与高保真交接.md)。

打开[收件箱](../prototype/index.html)即可体验。桌面显示邮箱、邮件列表和原信三栏；窄屏先显示列表，点一封进入阅读。首次使用采用两个虚构邮箱及其合成邮件。桌面通过右上角的「演示工作区」切换到空白工作区，手机在导航菜单的「工作区设置」里切换。空白工作区可直接导入测试邮件。

## 在多个邮箱间切换

桌面左栏上方是「所有收件箱」和「所有未读」，下方并列个人邮箱、工作室，以及各自收件箱的未读数。点账号只展开或收起文件夹，点文件夹才进入对应位置。工作区会记住哪些账号已展开。「更多文件夹」可直接进入各账号合并的草稿、已发送等列表。

手机点左上角的当前位置打开「邮箱与文件夹」。先选账号，在同一个抽屉中点「已发送」等文件夹才切换页面。关闭或按 Escape 取消本次选择。选定后顶栏会显示「工作室 · 已发送」。添加账号的「＋」位于「我的邮箱」旁。

从「所有收件箱」首次点「写邮件」，先在发件人一栏选定默认地址。以后可在「工作区设置」更换默认值，也可只切换本封邮件的身份。进入单个邮箱写信用当前账号，回复用原信所属账号，继续编辑草稿用草稿保存的身份。查邮件、查附件和使用 AI 时，可以在结果页调整查找范围，保留关键词或问题。合并列表会显示每封信的归属，重名邮箱会附地址。未绑定账号的 EML 可在「本地档案」查看。

## 可以动手试的流程

| 想体验的事情 | 操作和结果 |
| --- | --- |
| 看一封带附件的来信 | 打开「冬日散步指南 · 第二版打样确认」。展开「发给我」可核对收发地址。点封面可以预览打样、下载 PDF，或回复寄件人。 |
| 从附件找回原信 | 在「附件中心」输入「车票」，预览凭证后点「定位原信」。返回附件中心时保留文件名筛选。 |
| 找一张缺失的发票 | 进入「AI 查信」，把查找范围设为「工作室」，问「哪笔差旅报销还缺发票？」。点引用可核对苏州差旅原信，返回后继续看同一个问题。选择「个人邮箱」可以验证两个账号结果不同。报价示例还会核对同一账号中的往来回信。 |
| 写信、插短语、恢复草稿 | 点「写邮件」，或在桌面按 N。快捷文本插入光标所在位置，编辑会自动保存。刷新后可在草稿箱继续写；「模拟发送」把草稿移入本机发件箱。 |
| 写一封带附件的信 | 填好收件人和主题，在正文写「出行安排见附件」，然后点「模拟发送」。点提醒里的「补上附件」，选一个 2 MiB 以内的测试文件，保存草稿。刷新后继续编辑，发送到演示发件箱，从原信可下载同一文件。若正文确实无需附文件，可选择「仍然模拟发送」。 |
| 给同一个客户用固定邮箱 | 在收件人栏输入示例地址，点「为此收件人记住发件邮箱」。之后用其他邮箱写给此人，发送前会列出两个完整地址，可以一键切回，也可以保留本封选择。 |
| 出发前检查一个文件夹 | 从单个账号的收件箱点标题旁的下载图标，或进「本地存储 → 出差前备齐」。选邮箱和文件夹，看可读正文、附件原件和待保存字节，再点「一键备齐」。可固定此文件夹，在「此邮箱的离线策略」保存手机和电脑各自的偏好。 |
| 看压缩是否值得 | 在「本地存储」查看三个合成样本的磁盘占用，点「试用示例 EML」或选一份 8 MiB 以内的文件。试压展示原始字节、实际采用的载荷、节省量，可下载经过逐字节校验的原件。 |
| 导入再导出 | 在「本地档案」点导入图标，选择随附样信，或选择 256 KiB 以内的 UTF-8 纯文本 EML。导入到当前邮箱的本地档案，同一邮箱内相同字节只保留一封。在「全部邮箱」下导入时，原信归入独立的「本地档案」。导入的原信可通过「更多操作」导出原始 EML。 |
| 管理阅读状态 | 按账号、未读或含附件筛选；星标、已读与归档会保存在当前工作区。手机返回阅读列表时保留筛选和滚动位置。 |

## 用一份报价试两个功能

1. 打开「快捷文件夹」旁的＋，取名「客户报价」，关键词填「报价」，范围选「工作室」，筛选选「含附件」，点「固定搜索」。初始有两封已发报价。以后点击侧栏的「客户报价」，就会按这三个条件重新取结果。取消固定只移除这个入口。
2. 打开其中的「静物拍摄报价，供你参考」，在正文下方的「等对方回复」选择「3 天后」。打开侧栏工具「等对方回复」就能看到这封已过提醒时间的样信。从写信页预设相同期限的草稿，在模拟发送后会列在「待发送」，等发出才开始计时。
3. 进入「工作室 → 本地档案」，从导入按钮选择[静物拍摄报价的示例回信](../prototype/assets/静物拍摄报价-示例回信.eml)，离线包里同一份文件在 `assets` 下。回到「等对方回复」可查看对应回信。在「AI 查信」问「哪些报价还没有回复？」也能定位它。这封回信只有正文，因此「客户报价」里的两封带附件报价仍在原位。

跟进按 1、3 或 7 个自然日计时，在应用内显示到期项。本机原型会把相同账号内、原收件人较晚发来且信头明确引用原信的邮件认作回信。仅主题相同、来自其他邮箱或本地导入时间较晚，都不足以结束提醒。开发版尚未接入服务商后台同步和系统通知。

## 两组压缩数字

上方 **488 KiB** 是已有 Mac 文件系统实验中三个独立合成载荷的磁盘节省量。较短的文件压完仍占一个分配块，所以磁盘节省量可以是零。下方试压使用浏览器 GZIP，在内存中实际处理所选文件，按精确载荷字节比较，变大时保留原样。产品的 Rust 存储组件采用 Zstandard 分块，其接入和完整邮箱总占用属于后续工程验证。[本地压缩对照实验](../研究/本地压缩实验.md)

## 离线和数据范围

[下载离线包](../output/本地邮箱-离线原型.zip)后解压，在桌面浏览器打开整个目录里的 `index.html`。原型使用随包脚本、字体回退和本地附件。可在桌面缩窄窗口检查手机布局。临时预览服务器仅监听本机，手机实机无法经另一台设备的回环地址访问。

草稿、示例邮箱和导入邮件保存在当前浏览器的本地存储，以测试样信体验即可。本机 HTTP 预览会把主动备齐的打样 PDF 存入该账号的 IndexedDB，并回读校验；解压包内的原件已可离线使用，直接复用。空间页分别展示固定附件复用的载荷节省与三份实验样本的压缩节省。文件试压只使用内存。手机近 30 天正文、电脑保留已同步正文及附件按需等策略可保存，服务商后台同步接入后才会应用到真实邮箱。AI 查信继续使用本地规则检索。首批 163、QQ 的独立协议检查工具及联测进度见[接入验证](10-首批邮箱接入验证.md)。

## 本轮验证

11 月 21 日的走查覆盖桌面浅色、手机窄屏深色和断网解压包。固定「工作室＋报价＋含附件」起初命中 2 封，加入一封带附件的工作室报价后增至 3 封。取消固定后原信仍在。回复提醒能识别折行的 References 信头，也能从旧版已保存的原始 EML 恢复关联。对同主题、其他账号、本人发出的邮件、早于原信的邮件分别测试，均保留了原提醒。已打开的跟进页在另一标签导入匹配回信后自动更新。[桌面固定常用搜索](../output/playwright/固定常用搜索.png) · [手机等对方回复](../output/playwright/手机等对方回复.png)

桌面和手机视口都实测了选择默认邮箱、从其他账号回复、补附件、恢复草稿和下载原件。模拟发送后导出的自选 CSV 与输入逐字节相同。以「工作室 · 收件箱」为例，HTTP 预览中 7 封正文可读，附件从 4/5 份变为 5/5 份。断网后从原信下载的打样 PDF 共 355,912 字节，SHA-256 与原件一致。文件取用失败时可重试，刷新后保留账号、文件夹、固定选项和离线偏好。以上使用合成数据，桌面浏览器模拟手机尺寸。[发送前检查](../output/playwright/发送前检查.png) · [手机离线准备](../output/playwright/手机离线准备.png)

在合成数据中，统一收件箱共 14 封，个人邮箱与工作室各 7 封。工作室「已发送」有 2 封，个人邮箱的同名文件夹为空。实测从个人收件箱打开工作室「已发送」，桌面在工作室已展开时点 1 次，收起时点 2 次，手机从关闭的抽屉开始点 3 次。已验证这两种范围下的草稿、归档、附件、搜索、AI 引用、刷新和历史返回。

Chrome 桌面和手机模拟视口覆盖读写、存储、搜索、来源返回、浅深色与键盘操作。断网直接打开本地 HTML 时，下载的封面 PDF 与原件 355,912 字节完全一致；重新导出的中文测试 EML 保留原始换行与 UTF-8 BOM。手机列表滚动 650 像素后打开原信，应用返回和浏览器后退都恢复原位置。操作走查未产生外网请求。四端原生安装和真机表现仍待工程样机验证。
